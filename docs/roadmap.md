# Roadmap

## Day 1

- Scaffold frontend and backend.
- Add premium dashboard UI.
- Add mock locker API.
- Add Prisma schema.
- Prepare hardware adapter structure.

## Day 2

- Add PostgreSQL migration and seed data for 60 lockers.
- Replace in-memory locker state with Prisma-backed services.
- Add session tracking foundation for active rentals.
- Add frontend rollback and API error toast behavior.

## Day 3

- Add kiosk user flow: language, locker selection, duration, fake payment, QR and PIN.
- Add access credential model.

## Day 4

- Add admin dashboard views for sessions, revenue simulation, occupancy, and logs.
- Add realtime updates with WebSockets.

## Day 5

- Add demo reset mode, seeded City Mall zones, and polished presentation data.
- Add responsive tablet/kiosk polish.

## Day 6

- Add QR generation, PIN verification flow, and fake payment confirmation screens.
- Harden validation and error states.

## Day 7

- Presentation rehearsal, UI polish, deployment packaging, and final documentation.
